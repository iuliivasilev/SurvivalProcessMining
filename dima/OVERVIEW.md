## Вход

Журнал событий: **номер трассы**, **состояние** (активность), **время**.
Плюс два выбора аналитика: `START` (откуда считать время) и `TERMINAL` (какое событие считается исходом).

## Шаги

1. **Подготовка трасс.** Сортировка событий по времени. Трасса начинается с первого `START`
   и обрезается после первого `TERMINAL`. Подряд идущие одинаковые состояния склеиваются:
   время входа в состояние равно первому событию серии. Нулевые интервалы (одинаковые timestamp)
   заменяются на малое `min_duration`.

2. **Интервалы.** Каждая пара соседних состояний даёт **завершённый** интервал `(src, dst, t)`.
   Если трасса не дошла до `TERMINAL`, её последнее ожидание становится **цензурированным** интервалом
   `(src, ?, c)`, где `c` это время от входа в последнее состояние до последней записи трассы.
   Известно только, что `T > c`; следующее состояние неизвестно.

3. **Цензура по состояниям.** `q_s` = доля ожиданий в состоянии `s`, которые оборвались.
   Это описательная величина, в оценку параметров она не входит.

4. **Выбор семейства.** Для каждого перехода по завершённым интервалам подбираются
   exponential, lognormal, gamma, weibull; выбирается минимальный AIC.
   Если наблюдений меньше трёх, берётся exponential.

5. **Оценка p и параметров.** Для каждого состояния `s` отдельно, совместно по всем его выходам,
   максимизируется правдоподобие:

   * завершённый интервал `s→d` за `t`: множитель `p_sd · f_sd(t)`;
   * цензурированный через `c`: множитель `Σ_d p_sd · S_sd(c)`, то есть все возможные выходы,
     взвешенные вероятностью «ещё не завершился».

   Оптимизатор L-BFGS-B из scipy, `Σ p = 1` через softmax. Для сравнения считается наивная оценка
   только по завершённым интервалам.

6. **Сеть Петри.** Места: состояния и отдельное место `CENS`. Переходы `src→dst`
   с оценёнными p и распределениями; тихие переходы `src→CENS` с долей `q`.
   Схемы: сеть с фишкой в `CENS` после цензурированной трассы (4.1)
   и граф состояний с наблюдаемыми долями (4.2).

7. **Время до исхода.** Распределение времени от `START` до `TERMINAL` получается
   симуляцией восстановленной сети (выбор по p → время из распределения → …).
   Сравнивается с кривой Каплана–Майера по исходным трассам.

8. **Качество.** Истины нет, поэтому проверяется согласие с данными:
   −log L и AIC всей модели, KS по каждому переходу, расхождение с Капланом–Майером,
   fitness и precision Inductive Miner.
